# AnomalyLLM Service 

Высокопроизводительный асинхронный микросервис для мониторинга серверной инфраструктуры, детекции аномалий во временных рядах телеметрии и автоматической генерации экспертных инцидент-отчетов с использованием LLM.

## 📌 Ключевые возможности

- **Валидация входящих данных**: строгая типизация и фильтрация телеметрии на базе Pydantic v2.
- **Математическое ядро детекции**:
  - Расчёт базовых статистик ряда (максимум, медиана).
  - Сглаживание шума методом скользящего среднего (`rolling window`).
  - Определение тренда изменения температуры (растущий / стабильный / падающий).
  - Комбинированная детекция выбросов: статический порог (>80°C) и динамический порог на основе правила двух сигм ($\mu + 2\sigma$).
- **LLM-генерация рекомендаций**:
  - Интеграция с открытыми моделями через Groq API (`openai/gpt-oss-20b`).
  - Системный промпт-инжиниринг под формат инженерных сводок.
  - Паттерн **Graceful Degradation (Fallback)**: автоматический переход на детерминированные правила при сбоях сети или отсутствии внешнего API.
- **Хранение истории**: персистентность проверок в реляционной базе данных SQLite с защитой от SQL Injection (параметризованные запросы).
- **Автоматическая документация**: интерактивный OpenAPI / Swagger UI.
- **Надёжность**: покрытие ядра алгоритмов модульными тестами на `pytest`.

## 🚀 Быстрый старт

### 1. Клонирование репозитория и переход в проект
```bash
git clone [https://github.com/ВАШ_НИКНЕЙМ/anomaly-llm-service.git](https://github.com/ВАШ_НИКНЕЙМ/anomaly-llm-service.git)
cd anomaly-llm-service
```

### 2. Настройка виртуального окружения
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Задайте ваш API-ключ в файле `.env`:
```ini
GROQ_API_KEY=gsk_your_api_key_here
LLM_MODEL=openai/gpt-oss-20b
```
*(При отсутствии ключа сервис продолжит работу в автономном режиме благодаря локальному Fallback-генератору).*

### 5. Запуск сервиса
```bash
uvicorn app.main:app --reload
```
Сервис станет доступен по адресу: `http://127.0.0.1:8000`  
Интерактивная документация Swagger UI: `http://127.0.0.1:8000/docs`

## 📡 API Эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/` | Healthcheck состояния сервиса |
| `POST` | `/api/v1/analyze` | Анализ массива температур, поиск аномалий, генерация рекомендации и сохранение в БД |
| `GET` | `/api/v1/history` | Получение последних записей мониторинга из базы данных (параметр `limit`) |
| `GET` | `/docs` | Swagger UI документация и ручное тестирование |

### Пример тела запроса (`POST /api/v1/analyze`):
```json
{
  "server_id": "srv-prod-01",
  "temperatures": [42.0, 44.5, 43.0, 98.2, 45.0]
}
```

### Пример ответа сервиса:
```json
{
  "server_id": "srv-prod-01",
  "status": "anomaly",
  "anomalies_found": [98.2],
  "max_temp": 98.2,
  "recommendation": "Сервер достиг критической температуры 98.2 °C, что указывает на перегрев оборудования. Немедленно проверьте систему охлаждения и завершите ресурсоёмкие фоновые процессы."
}
```
